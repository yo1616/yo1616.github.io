01

Project Overview

YOUR LIFE IN NTU IM is a C++ terminal-based maze game inspired by student life in the Department of Information Management at National Taiwan University. Players navigate maps through keyboard controls, collect items and academic credits, and avoid enemies and obstacles across different stages.

The game incorporates credits, GPA, items, and stage progression as interactive mechanics, turning familiar elements of university life into challenges and decisions that influence the player's experience and game state.

The team used C++ and object-oriented programming to organize characters, items, and game-state functionality, allowing different components to interact through defined rules and form a coherent terminal-game experience.

02

My Contributions

My primary contribution involved implementing item-related features in C++, helping translate gameplay concepts into executable logic and connect item interactions with character behavior and game-state changes.

Through this work, I gained hands-on exposure to object-oriented programming concepts such as classes, objects, and inheritance. I learned how item functionality relates to character attributes and gameplay rules, and how a clearer program structure can help organize interactive features.

Beyond programming, I also contributed to project documentation and report preparation, helping explain the game's design, functional structure, and implementation approach in a format that could communicate the team's development work.

Working with other team members gave me experience in module coordination, integration discussions, and technical documentation, while strengthening my understanding of how independently developed features fit into a larger program.

03

Programming & Game Mechanics

The game uses a text-based terminal interface to display maps and character positions. Players navigate through keyboard input, while the program manages movement, collisions, item interactions, stage progression, and transitions between game states.

The team applied object-oriented programming (OOP) to structure characters, items, and related game elements, making it possible to organize different types of behavior through classes and defined interaction rules.

The item system plays an important role in gameplay. Different item types and effects allow players to collect resources or change aspects of the game state as they explore. By contributing to this part of the implementation, I gained experience translating gameplay rules into conditional logic and object interactions.

The development process also revealed compatibility differences in keyboard input handling between macOS and Windows, highlighting the importance of considering execution environments when building interactive terminal applications.

04

Project Outcomes

The team completed a C++ terminal maze game inspired by NTU Information Management student life, combining character movement, stage exploration, item interactions, and academic-themed mechanics such as credits and GPA. The design and implementation were presented through project slides and a written report.

For me, this project provided practical experience in applying C++ and object-oriented concepts to an interactive program. Implementing item-related features and collaborating with the team helped me understand how to break down functionality and coordinate different parts of a software project.

The experience also strengthened my foundations in program logic, debugging, and technical communication, supporting my subsequent work in system development and software projects.
