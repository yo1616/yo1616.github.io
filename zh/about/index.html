ABOUT / PATRICK

關於我

我是蔡承佑（Patrick），目前就讀於國立臺灣大學資訊管理學系。我對科技與商業的交會特別感興趣，希望透過資訊技術與資料分析，理解並解決真實情境中的問題。

在學習與專案實作過程中，我逐漸發現自己不只對技術實作有興趣，也重視問題定義、需求分析與系統整合。對我而言，好的技術方案不只是能夠運作，更需要理解使用者的需求、實際工作流程，以及技術能夠帶來的價值。

我曾擔任AI 錯題學習助理平台的專案組長，負責需求訪談、系統架構與 REST API 規劃，並協調團隊完成各功能模組的整合。此外，我也透過機器學習、金融資料分析及 HCI 使用者研究等專案，累積Python 資料處理、統計建模、技術分析與研究洞察的實作經驗。

除了技術專案，我也參與學生組織的預算管理與活動企劃，學習如何在資源與時間限制下協調不同角色、推動團隊完成共同目標。

目前我持續探索AI 產品、科技顧問、商業分析與資料分析等職涯方向，希望結合資訊管理的跨領域背景，累積從問題分析到技術實作與商業應用的完整能力。
