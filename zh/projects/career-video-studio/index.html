專案內容

影音製作常需要在轉錄、字幕與渲染工具間重複操作。我設計以 Python 串接 Whisper 與 FFmpeg 的流程，拆分轉錄、文字整理、字幕規劃與輸出模組，並使用 Codex 與 ChatGPT 協助原型開發和除錯。

Project 文件記錄了 Pytest 自動化測試與真實媒體檔案驗證；本次未取得對應程式與媒體成果，因此不列測試通過數、節省時間或成品品質指標。人工確認保留在內容準確性與最終剪輯決策上。後續可補上具代表性的輸入／輸出範例、失敗案例及可重現測試紀錄。
